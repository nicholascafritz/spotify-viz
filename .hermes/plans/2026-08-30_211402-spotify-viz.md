# spotify-viz Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build a standalone `spotify-viz` command that renders an audio-reactive, liminal ASCII scene from PipeWire output while displaying and controlling the local ncspot Spotify player through MPRIS.

**Architecture:** CAVA owns PipeWire capture and FFT processing, writing a local raw frequency-band stream. A Python 3.13 renderer reads that stream without blocking its frame loop, queries `playerctl --player=ncspot` at a low cadence, and writes a truecolor ANSI alternate-screen canvas. Pure signal, layout, scene, config, and state logic remain separate from subprocess adapters so they can be exercised with fakes.

**Tech Stack:** Python 3.13, uv, pytest, standard-library ANSI/termios rendering, CAVA 0.10.4+ raw output, playerctl, PipeWire, Kitty truecolor.

---

## Requirements fixed by the approved design

- Separate launch command: `spotify-viz`; never embeds into or restarts ncspot.
- The visualizer consumes actual PipeWire output audio, not an estimated playback timer.
- Main view is a full alternate-screen liminal ASCII corridor/grid with impossible doors, debris, scanline fragments, and a distant void.
- Bass bends perspective, mids move debris/doors, treble creates fine glitches, and transients trigger brief scene jumps.
- Palette: gunmetal-black background, phosphor-green geometry, cyan reactive edges/horizon, amber warnings, red errors; no rainbow cycling.
- Bottom readout contains track, state, elapsed time, and audio-tap state. It hides in compact mode.
- Keys: `q` quit, `Space` scoped ncspot play/pause, `m` cycle scenes, `h` toggle help.
- Missing MPRIS must not stop the audio scene. Missing CAVA/PipeWire must retain a calm frame and report the tap failure.

## Risks and decisions

- CAVA’s documented raw-output framing must be checked against the Debian Trixie package before committing the adapter; the parser frame width belongs in one tested constant.
- PipeWire default sinks can change when output devices change. Source discovery must run at launch, and the config override must remain available.
- `playerctl` sees several MPRIS players on this host; every playback-control command must include `--player=ncspot`.
- Direct ANSI rendering is chosen over curses because Kitty truecolor is a stated design requirement. Terminal lifecycle tests are mandatory to avoid leaving a broken shell on failures.
- No remote service, credentials, GUI, song-download functionality, or generic multi-player selector is in scope.
